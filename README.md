🎯 Guess the Number

A responsive Guess the Number game built with HTML, CSS, and JavaScript. Features input validation, guess history, restart animation, keyboard support, and a modern glassmorphism UI.

🚀 Features

o 🎲 Random number generation
o 🔢 Input validation
o ❌ Duplicate guess detection
o 📉 Attempts counter
o 📜 Guess history
o ⌨️ Enter key support
o 🔄 Restart game with animation
o 📱 Fully responsive design
o ✨ Modern Glassmorphism UI

📚 What I Learned

While building this project, I learned:

o DOM Manipulation
o Event Handling (`click` & `keydown`)
o Input Validation
o JavaScript Functions
o Arrays and Objects
o Array Methods (`some()`, `forEach()`)
o Dynamic DOM Updates
o Conditional Logic
o Responsive Design with CSS Grid & Flexbox
o CSS Transitions & Animations
o Writing Cleaner and Reusable Code
